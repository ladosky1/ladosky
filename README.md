## About

I started with frontend development and gradually moved into backend systems, databases, authentication, APIs, and real-time applications.

This portfolio documents that progression through the products I've built and the problems I've worked through along the way and this portfolio is live and i will keep updating with my projects.

## Featured Projects

### AnimeLad

An anime discovery application that started as a frontend React project using the AniList GraphQL API and later evolved into a full-stack application with an Express backend, authentication, MongoDB, and a watchlist system.

**Stack:** React, JavaScript, Express, MongoDB, GraphQL

### JobApplyTracker

A mobile-first job application tracker that began with local storage and later evolved into a full-stack application with authentication, persistent data, and a MongoDB backend.

**Stack:** React, Vite, Tailwind CSS, Express, MongoDB, JWT

### KudiTrack

A personal finance tracker built while going deeper into TypeScript and structured application development. It includes transaction management, smart input parsing, data visualization, and persistent data.

**Stack:** React, TypeScript, Mantine, Recharts, Express, MongoDB

### PulseHUB

A real-time community platform focused on discussion and interaction. It represents my current step into more complex full-stack systems, including authentication, friendships, messaging, communities, sessions, and real-time communication.

**Stack:** React, TypeScript, Mantine, Express, MongoDB, Socket.io
